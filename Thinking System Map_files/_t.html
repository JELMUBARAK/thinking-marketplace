Thinking System Map

How a problem moves through the thinking coach: from the first message to a journaled decision, with the subagents and scripts each stage calls on. The coach runs one stage per reply and waits for the user before moving on.

The coaching flow

Solid arrows: the main pathDotted arrows: a subagent or script the stage callsCylinder: the decision journal

Inside the signal check

New in 0.6.0. It runs only when the user brings data and agrees, or asks for patterns outright. Every pattern counts as "eyeballed, not tested" until a test has run.

Parts

Skills

  • thinking-coach runs the flow above
  • decision-review closes the loop after acting

Subagents (deep tier only)

  • librarian past decisions and calibration (haiku)
  • researcher outside base rates with sources (sonnet)
  • analyst tests patterns in data (sonnet)
  • quant expected costs and flip points in code (sonnet)
  • red-team independent critic (opus)

Scripts

  • journal.py due, find, stats, add, update
  • extract.py reads uploaded files
  • signal_tests.py power, trend, compare, assoc, change, scan

Memory and checks

  • Journal at ~/.claude/thinking-system/journal.jsonl
  • Session-start hook lists overdue reviews
  • 21 eval cases in evals/, run after every SKILL.md change
