# Machine library

Everyday machines whose rules are written down once. To make an analogy, match the concept's rule table to one machine row by row. A concept rule with no machine rule is a "breaks here" line. Add a machine only when no existing one fits.

| Machine | Its rules (what it really does) | Fits mechanisms like |
|---|---|---|
| **Chain of people passing work on** | each person keeps their own notes and waits; the last one answers; answers come back in reverse order; limited desks; no "stop" rule means it never ends | recursion, delegation, call stacks |
| **Random sharing of tokens** | tokens move between holders at random; nobody steers; the states with the most possible arrangements win on average; small groups fluctuate; more space means more arrangements | entropy, diffusion, statistical drift |
| **Auction market** | many bidders, limited goods; more money or more bidders chasing the same goods raises bids across the market; expectations feed bids; a fixed debt shrinks as bids rise | inflation, prices, bubbles |
| **Leaky bucket** | level = what comes in minus what leaks out; the level and the fill rate are different things; a longer pipe means a delay | stocks and flows, debt, CO2, drug levels |
| **Thermostat** | measures, compares with a set point, pushes back; delays cause overshoot | feedback, homeostasis, central banks |
| **Ratchet** | moves one way easily, the other only with work | irreversibility, one-way processes |
| **Learning security desk** | general door checks for everyone at once; a suspicious case is sent to a desk that makes a specific ban list; the list is kept; staff can turn on their own people | immune system, spam filtering |
| **Fair-coin check** | assume the coin is fair; ask how often a fair coin gives a result this extreme; the answer is about fair coins, not about this coin | p-values, hypothesis tests |
| **Spinner on a board with slots** | the arrow points anywhere until played; on play it drops into one slot with a squared chance and then stays there; turning the board changes which slots it sits between | measurement in a basis (no cancellation: chances only add) |
| **Club with a yearly vote** | members can remove the committee peacefully; the vote means something only while members can speak and organise | electoral democracy, accountability |
| **League with a rulebook** | votes decide most things, but a rulebook and referees protect rights no vote can remove | liberal democracy, constitutions |
| **House meeting** | decisions come from talking through reasons among equals, then choosing | deliberative democracy, consensus |
| **Queue** | arrivals versus service rate; past full use, the wait grows without limit | traffic, servers, hospitals |
| **Spring** | pull it and it pulls back harder the further you pull; past a limit it deforms for good | elasticity, restoring forces, thresholds |
